Курс «Основы веб-разработки»

Курс знакомит с созданием веб-сайтов. В программу входят HTML, CSS, Python и базы данных.

1. Введение в веб-технологии

Изучается работа интернета: клиент-серверная архитектура, протокол HTTP, домены и хостинг.

1.1 Как работает браузер

Браузер загружает HTML, строит DOM-дерево, применяет CSS и выполняет JS. Как говорится, понимание процесса помогает писать производительный код.

1.2 Протоколы и безопасность

Обсуждаются принципы работы HTTPS, передача данных и базовые меры безопасности.

2. Язык разметки HTML

HTML — фундамент веб-страницы. Изучается структура документа, основные теги и семантика.

2.1 Структура документа

Обязательные элементы: <!DOCTYPE>, <html>, <head>, <body>. Важно: порядок вложенности влияет на отображение.

2.2 Текстовая разметка

Изучаются заголовки <h1>...<h6>, абзацы <p>, списки <ul>/<ol>, теги форматирования — важное и акценты.

2.2.1 Заголовки и иерархия

На странице только один <h1>. Заголовки идут по порядку, не пропуская уровни — важно для SEO.

3. Каскадные таблицы стилей (CSS)

CSS отвечает за внешний вид: цвета, шрифты, расположение элементов.

3.1 Селекторы и свойства

Изучаются селекторы (по тегу, классу, id), задание цветов, размеров и отступов.
